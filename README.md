# MUSIC-GENRE

A project focused on music genre classification or music-based prediction using data science methods.

## Overview
This repository explores music-related data and applies a classification workflow to group or predict musical styles.

## Tech Stack
- Python
- Jupyter Notebook
- Data analysis
- Machine Learning

## Run locally
1. Create a virtual environment.
2. Install the dependencies.
3. Open the notebook or run the project scripts.

```bash
jupyter notebook
```

## Notes
This project is a useful data science and ML example for music-related classification tasks.
